# Dada's Sweets & Restaurant

Premium, food-first website for Dada's Sweets & Restaurant, Chandausi.

## Direction

The visual direction is an editorial, premium restaurant experience inspired by the interaction principles used in the separate Raj Delight project. **Raj Delight itself is not modified by this project.**
